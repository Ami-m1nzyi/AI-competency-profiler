# AI Competency Profiler

## Публикация на Vercel

Приложение размещается одним проектом: `vercel.json` собирает интерфейс Vite и
сервер Flask отдельно, а запросы `/api/` направляет серверу. В настройках Vercel
Root Directory оставляется пустым, Node.js — 24.x. Не выбирайте `backend` как
корневую папку при использовании этого файла конфигурации.

В облаке используются Neon Postgres (`DATABASE_URL`) и приватное Vercel Blob
(`BLOB_READ_WRITE_TOKEN`). SQLite и локальные загрузки сохраняются для разработки.
Секреты задаются в настройках окружения Vercel, а не в репозитории:
`SECRET_KEY`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `ADMIN_EMAIL`, `OPENROUTER_API_KEY`.
Для почты дополнительно нужны действующие `SENDER_EMAIL` и `SENDER_PASSWORD`.
Администратор создаётся при первом запуске; демонстрационные аккаунты в облаке
не создаются. Регистрация студентов открыта, преподаватели используют приглашения.

Вопросы выбираются из существующего банка и сохраняются отдельно для каждой
попытки в базе данных. `GENERATE_AI_QUESTIONS=1` включает дополнительную генерацию
вопросов через OpenRouter. ИИ-рекомендации работают при действующем ключе и балансе;
при недоступности провайдера используются базовые рекомендации. Документы до 4 МБ
сохраняются в приватном хранилище и выдаются после проверки прав доступа.

Проверки: `python -m pytest -q tests`, затем `npm run lint` и `npm run build` из
папки `frontend`. `/api/health` проверяет доступность сервера и базы.

## О проекте

**AI Competency Profiler** решает проблему отсутствия у студентов объективного понимания своего уровня подготовки и вектора профессионального развития, а также помогает преподавателям автоматизировать мониторинг успеваемости и формирование сбалансированных проектных команд.

### Ключевые возможности:
* **Адаптивное тестирование по 5 векторам компетенций:**
  * Алгоритмическое мышление (*algo*)
  * Разработка и кодинг (*coding*)
  * Дизайн-мышление и UX/UI (*design*)
  * Предпринимательство и стартап-мышление (*entrepreneur*)
  * Командная работа и лидерство (*teamwork*)
* **Интерактивная карта компетенций:** визуализация результатов в виде радарной диаграммы (Recharts) с определением ведущей IT-роли (Разработчик, Аналитик, UX/UI Дизайнер, Стартап-лидер, Универсальный специалист).
* **Учет времени решения:** система фиксирует время ответа на каждый модуль, помогая ИИ выявлять зоны неуверенности студента.
* **Персонализированный ИИ-советник:** интеграция с Large Language Models (LLM) через OpenRouter API для генерации детального карьерного плана, списка литературы и онлайн-курсов.
* **Кабинет преподавателя:** сквозная аналитика группы и автоматическое формирование сбалансированных команд (по 4–5 человек) для хакатонов и курсовых проектов с помощью ИИ.
* **Цифровое портфолио:** загрузка дипломов, сертификатов и ссылок на GitHub-проекты.
* **Панель администратора:** мониторинг пользователей, управление ролями, обработка тикетов техподдержки и переключение тем (Светлая / Тёмная).

## Стек технологий

* **Frontend:** React 18, Vite, CSS Modules, Recharts, Lucide Icons
* **Backend:** Python 3, Flask (REST API), Flask-CORS, SQLAlchemy / SQLite
* **AI Engine:** OpenRouter API (LLM) + локальный алгоритмический fallback-генератор
* **Аутентификация:** Сессии / Токены с разделением ролей (*Студент*, *Преподаватель*, *Администратор*)

## Быстрый запуск

### Вариант 1: Автоматический запуск (Windows)
Просто запустите скрипт в корне репозитория:
```cmd
start.bat
```
Скрипт автоматически установит зависимости бэкенда и запустит сервер по адресу `http://localhost:5000`.

---

### Вариант 2: Ручной запуск

#### 1. Настройка и запуск бэкенда:
```bash
cd backend
python -m pip install -r requirements.txt
cp .env.example .env   # укажите ваш OPENROUTER_API_KEY при необходимости
python app.py
```
Сервер будет доступен на `http://localhost:5000`.

#### 2. Запуск фронтенда (в режиме разработки):
```bash
cd frontend
npm install
npm run dev
```

#### 3. Сборка фронтенда:
```bash
npm run build
```
Собранные статические файлы копируются в папку `backend/static/` для отдачи через Flask.
